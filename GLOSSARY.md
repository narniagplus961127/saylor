# SayLor

SayLor turns natural speech into written text, with optional translation into a selected output language.

## Language

**Dictation**:
Turning speech into clean written text while preserving its language and intended meaning. This is SayLor's default workflow.
_Avoid_: Translation when referring to same-language output

**Translation**:
Rendering the meaning of speech in a selected output language. This is optional rather than the default dictation workflow.

**Mixed-language speech**:
A recording containing more than one spoken language, including switches within a sentence. SayLor initially prioritizes English, Mandarin, and Malay.
_Avoid_: Treating a recording's detected language as proof that it contains only one language

**Output language**:
The language selected for translated text.
_Avoid_: Spoken language when referring to the requested translation language
